# Selenium Tool

`selenium-server-4.44.0.jar` được tải từ release chính thức của Selenium:

```text
https://github.com/SeleniumHQ/selenium/releases/download/selenium-4.44.0/selenium-server-4.44.0.jar
```

Selenium Manager đi kèm Selenium sẽ tự tìm Microsoft Edge và tải driver tương thích trong lần chạy đầu tiên nếu cần.
